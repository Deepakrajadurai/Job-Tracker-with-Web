# Sign-in button logos

The project does not ship the Google or GitHub logos. Download the official files from the
providers and save them here. The login page shows them as soon as the files exist.

| File name | Where to get it |
|---|---|
| `google.svg` (or `.png`) | Google "Sign in with Google" branding guidelines: https://developers.google.com/identity/branding-guidelines (download the logo files there) |
| `github.svg` (or `.png`) | GitHub logos page: https://github.com/logos (use the GitHub mark) |
| `oidc.svg` (optional) | Your other login provider's brand page, e.g. Microsoft |

Use the files as they come (no recolouring or stretching). Commit them to the repository so the
Docker image contains them.
